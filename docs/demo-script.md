# Precision Tuner 功能演示视频脚本

> 用途:按此脚本录制应用功能演示视频(竖屏录屏即可)。
> 建议总时长 4–6 分钟;每场标注了操作、旁白要点与建议时长。
> 录制前:在"设置 → 版本信息"确认版本号为 **1.1.6**;主题建议用默认或"专业"主题。

---

## 场景 1 · 开场(约 15s)

- **画面**:桌面应用图标 → 点击启动,展示浅色启动页 → 进入主界面。
- **旁白**:"Precision Tuner——集乐器调音、半音阶调音、节拍器与视听练耳于一体的专业调音助手,AI 辅助音高检测。"

## 场景 2 · 乐器调音(约 60s)

- **操作**:
  1. 底部栏切到"乐器调音";点顶部乐器名,切换 吉他 / 尤克里里 / 小提琴 等,展示乐器列表。
  2. 弹一根弦,展示**自动识别琴弦**("第 1 弦 · E4")与指针逐渐归中。
  3. 手动点选某一弦,锁定目标;点"参考音"按钮,播放钢琴参考音,再跟着调。
  4. 设置 → 调弦预设 → 新增一个自定义调弦(如 Drop D),保存后回到乐器页选中它。
- **旁白**:"内置十一种乐器与多种调弦;自动识别当前琴弦,也可手动锁定;播放参考音辅助校准;自定义调弦可持久保存。"

## 场景 3 · 半音阶调音 + 频谱(约 50s)

- **操作**:
  1. 切到"半音阶调音",弹一个音,展示律制切换:十二平均律 → 五度相生律 → 纯律,偏差变化。
  2. 弹低音弦,展示**频谱**:主峰满格、谐波逐级下降、安静时频谱仍显示(常显)。
  3. 设置 → 调音选项,拖动"基准音 A4"(415–466),切回半音阶看顶部 A4 数值变化;再回乐器页确认同样生效。
- **旁白**:"三种历史律制一键切换;实时频谱采用专业功率比例显示,噪声门限下也常显;基准音 A4 全局生效并持久保存。"

## 场景 4 · 节拍器(约 40s)

- **操作**:
  1. 切到"节拍器",选一个 BPM 预设(或点按测速打几下),点播放——**强调首拍即刻响应、无延迟**。
  2. 切换 拍号(4/4、3/4)、细分(八分/三连音/十六分)、重音开关;展示圆形进度环。
- **旁白**:"BPM 预设与点按测速,支持拍号、细分与重音;首拍即时起播,节拍精准不拖拍。"

## 场景 5 · 视听练耳(约 60s)

- **操作**:
  1. 底部切到"视听练耳",选择 **单音识别**,开始无尽模式,播放-作答,展示反馈(正确/错误音效、准确率环)。
  2. 返回,选择 **五线谱识谱**,展示选项与谱面升降号一致(选项不可靠升降号排除)。
  3. 再展示 **节奏听写**:播放节奏,点击节拍作答。
  4. 展示 挑战模式(五条命)或 测试模式,难度切换 简单/中等/困难。
- **旁白**:"六种练习:单音、音程、和弦、音阶、五线谱识谱与节奏听写;无尽/挑战/测试三种模式,三档难度,游戏化反馈。"

## 场景 6 · 设置与主题(约 50s)

- **操作**:
  1. 进入 设置,展示**多级分区**:主题 / 调音选项 / 调弦预设 / 版本信息。
  2. 进入 主题,切"系统主题",逐一点选 **黑金 / 樱花粉 / 专业**,展示全界面配色变化;切回"自定义设置",切换深/浅色与六种主题色。
  3. 回到设置首页,点 **恢复默认设置**,确认后主题回到默认。
- **旁白**:"设置按功能分区;八套系统主题一键换肤,或自定义深浅与主题色;恢复默认设置一键还原。"

## 场景 7 · 更新检测(约 40s)

- **操作**:
  1. 设置 → 版本信息,展示版本号与**作者 QQ(点击复制)**。
  2. 点 **检查更新**:有新版时展示"发现新版本"弹窗 → **下载并安装**,展示下载进度 → 自动进入系统安装器。
- **旁白**:"版本信息页提供一键检查更新,应用内直接下载并自动安装,保持最新功能。"

## 场景 8 · 结尾(约 10s)

- **画面**:回到主界面,停留 2 秒。
- **旁白**:"Precision Tuner,你的随身调音助手。喜欢就点个关注,有问题欢迎通过 QQ 联系作者,我们下期再见!"

---

## 录制建议

- 全程竖屏,分辨率建议 1080×1920;每个场景开始前停顿 1 秒再操作。
- 需要收音的场景(调音、节拍器、练耳)建议外接麦克风或保持安静环境。
- 旁白可后期配音;若一次录不完,按场景分段录制再拼接。
