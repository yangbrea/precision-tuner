Piano reference-tone samples
============================

Source: "钢琴声音" (Piano Sounds) sample pack
  GitHub archive "18b0b-main" (main branch), archived 2023-06-21.
  88 WAV files, one per MIDI note 021 (A0) - 108 (C8),
  1-second stereo 44.1 kHz 16-bit; converted to mono 44.1 kHz for this app.
